# Brand Name Generator

A simple Python script that generates a brand name idea by combining the
city you grew up in with your pet's name.

## How it works

The script asks two questions:

- Which city did you grow up in?
- What's your pet's name?

It then combines your answers into a possible brand name.

## How to run

python brand_new_generator.py

## Example

Which city did you grow up in?
Milwaukee
Enter the name of your pet:
captian
Your brand name could be: Milwaukee captian
